## ฟังก์ชันที่เพิ่ม

1. **Live GPS ในหน้าแผนที่:** หมุดสีน้ำเงินเลื่อนตามพิกัดจาก `watchPosition()`; แสดงค่าความแม่นยำ; หยุดเมื่อออกจากหน้าแผนที่/ซ่อนแท็บ; มุมมองแผนที่ไม่เลื่อนตามเมื่อผู้ใช้ลากแผนที่เอง; มีปุ่มเริ่ม/หยุดและปุ่มกลับมาตำแหน่งปัจจุบัน ไม่บันทึกเส้นทางลงฐานข้อมูล
2. **Smart Search บนหน้าแผนที่:** ค้นหาโครงการ ชื่อหน่วยงาน รหัสเสา รหัสลูกถ้วย ชื่อผู้ตรวจ หรือพิกัดในช่องเดียว; แสดงผลที่เลือกได้; แตะเพื่อเลื่อนไปยังหมุดเสาหรือดูรายละเอียด; พิกัดคู่ค้นหาในรัศมีประมาณ 15 เมตร
3. **สรุปข้อมูลรายเสา:** หน้าโครงการแสดงจำนวนลูกถ้วยที่ตรวจแล้ว/ทั้งหมด, ประวัติ, สถานะตรวจไม่ครบและความเสียหายสูงสุด; หน้ารายละเอียดแสดงแถบความคืบหน้า; ใช้ข้อมูลประวัติรายลูกล่าสุด ไม่เอาจำนวนบันทึกมานับแทนจำนวนลูก
4. **หน้าตรวจสอบ:** เปลี่ยนหัวข้อเป็น `ระบุจำนวนลูกถ้วย` โดยใช้ช่องข้อมูล `units` เดิม

## ติดตั้งผ่านคอมพิวเตอร์ Windows (แนะนำ)

1. เข้า <https://github.com/patiphan230744/Insulator-AI-V5> แล้วกด **Code → Download ZIP** หรือใช้โฟลเดอร์ Repository ที่มีอยู่
2. แตกไฟล์ ZIP ของ Repository ออกมา
3. แตก ZIP ชุดปรับปรุงนี้ **ทับโฟลเดอร์หลักที่มี `index.html`** ให้ได้โครงสร้าง:

   ```text
   Insulator-AI-V5/
     index.html
     apply_v5_update.py
     ติดตั้ง_บน_Windows.bat
     js/
       core.js                  (ไฟล์เดิม)
       projects.js              (ไฟล์เดิม)
       v5-data.js               (ไฟล์เดิม)
       v5-enhancements.js       (ไฟล์ใหม่)
     css/
       v5.css                   (ไฟล์เดิม)
       v5-enhancements.css      (ไฟล์ใหม่)
   ```
4. ดับเบิลคลิก `ติดตั้ง_บน_Windows.bat` หรือเปิด CMD ในโฟลเดอร์และรัน `py apply_v5_update.py` (ต้องมี Python 3)
5. เมื่อขึ้นข้อความสำเร็จ ให้ตรวจ `index.html` ที่ปรับแล้ว มีการอ้างอิง `v5-enhancements.css` และ `v5-enhancements.js`
6. อัปโหลดไป GitHub โดยคงตำแหน่งไฟล์: **`index.html`, `js/v5-enhancements.js`, `css/v5-enhancements.css`** แล้ว Commit → รอ GitHub Pages Deploy และรีเฟรชแบบไม่ใช้แคช (Ctrl+F5)

## วิธีติดตั้งด้วย GitHub Web โดยไม่ใช้ Python

- สร้างไฟล์ `js/v5-enhancements.js` และ `css/v5-enhancements.css` ด้วยเนื้อหาใน ZIP นี้
- แก้ `index.html` สามตำแหน่ง:
  - ก่อน `</head>` ใส่ `<link rel="stylesheet" href="css/v5-enhancements.css?v=20261117">`
  - หลัง `<script src="js/bootstrap.js"></script>` ใส่ `<script src="js/v5-enhancements.js?v=20261117"></script>`
  - เปลี่ยน `<label for="units">จำนวนลูกถ้วยจริงบนเสานี้ (ปรับได้ ไม่จำกัดไว้ 3 ลูก)</label>` เป็น `<label for="units">ระบุจำนวนลูกถ้วย</label>`

## ข้อมูลและการทดสอบ

- การปรับปรุงนี้ **ไม่ลบประวัติ IndexedDB, localStorage, รูปภาพ หรือ Firebase** และไม่เขียนพิกัดผู้ใช้ลงฐานข้อมูล
- ยังใช้ Firebase แบบเดิม คือซิงก์ข้อมูลด้วยตนเอง; ยังไม่ได้เพิ่มระบบสิทธิ์แบบแชร์โครงการข้ามบัญชี
- สถานะลูกถ้วยยังอ้างอิงผล AI ของแอป (หากอยู่ DEMO เป็นข้อมูลจำลอง)
- ควรทดลองบนมือถือผ่าน HTTPS จริง: อนุญาต GPS, เดินเปลี่ยนตำแหน่ง, เลื่อนแผนที่เอง, กดกลับตำแหน่งฉัน, ค้นรหัสเสา/พิกัด, เปิดรายละเอียด, ทดสอบประวัติเดิม
- ระบบติดตาม GPS ในแท็บที่เปิดแผนที่เท่านั้น ไม่รองรับการติดตามเบื้องหลังขณะปิดแอป
- ควรสำรองข้อมูล JSON จากหน้า Settings ก่อนเริ่มอัปเดตทุกครั้ง
